A. Capaian  Pembelajaran  
Pada pertemuan ini akan dijelaskan mengenai cara 
membuat file executable dan installer dari aplikasi yang 
sudah dibuat, mengidentifikasi software pendukung untuk 
membentuk Deployment – Installer, membuat Deployment  - 
Installer menggunakan software pendukung Launch4j dan

B. Materi  
1. Software pendukung Deployment - Installer  
File executable adalah jenis file yang dapat 
diterjemahkan dan dijalankan langsung oleh kernel 
tanpa harus membutuhkan aplikasi tambahan. Insta ller 
merupakan aplikasi yang dibuat bertujuan untuk 
mengekstrak atau memasukan aplikasi baru ke 
komputer dan menyiapkannya untuk eksekusi 
selanjutnya.
