B. Materi  
1. Apa itu MVC?  
MVC adalah sebuah arsitektur perancangan kode 
program, tujuannya untuk memecah kode program 
utama menjadi 3 komponen terpisah dengan tugas yang 
spesipik. MVC adalah kepanjangan dari Model -View -
Controller yang merupakan suatu metode atau konsep 
yang sangat populer dalam membangun sebuah aplikasi 
web yang awalnya menggunakan bahasa pemrograman 
smalltalk yang mengisahkan bisnis logic atau alur piker 
datalogic atau penyim panan data dan presentation logic 
atau antarmuka aplikasi atau secara sederhana adalah 
misalkan proses data dan desain.  
 
 
299 Pemrograman 2  Kenapa kita perlu memisahkan menjadi 3 komponen,  
Aplikasi apapun baik itu web atau dekstop yang 
paling sering mengalami perubahan adala h bagian user 
interface nya, penggabungan antara user interface 
dengan business logic akan menyebabkan terjadinya 
refactor atau perubahan aplikasi menjadi sangat 
kompleks, perubahan yang terjadi pada salah satu 
bagian akan memiliki potensi mempengaruhi bag ian 
yang lain.  
Arsitektur MVC ini menjawab permasalan tersebut 
dengan membagi bagian -bagian ap;ilasi menjadi Model, 
View dan Controller, memisahkan bagian tersebut dan 
mebuat interaksinya, perubahan yang terjadi antar 
bagian tidak akan terlalu saling memp engaruhi, kecuali 
memang terjadi perubahan yang krusial. Jika 
digambarkan interaksinya seperti ini.

Dalam komponen MVC terdapat 3 komponen, yaitu  
a. Model, sesuai dengan namanya komponen yan g 
pertama adalah model, model biasanya berkaitan 
dengan data dan interaksi ke database atau

data dari aplikasi yang berupa basis data atau pun 
berupa data lain. Misalnya dalam bentuk file xml, file 
teks, ata upun webservice, didalam model biasanya 
akan berisi class dan fungsi untuk mengambil serta 
melakukan update dan menghapus data website,

c. Controller adalah bagian yang m engatur hubungan 
antara bagian model dan bagian view, didalam 
bagian controller berisi kelas -kelas dan fungsi -fungsi, 
yang memproses permintaan dari view kedalam

mengakses data telah diberikan kepada bagian

memanggil model untuk melakukan akses ke basis

5. STRUTS  
Struts adalah aplikasi framework open source 
yang didesain untuk membantu para developer dalam 
membangun arsitektur aplikasi berdasarkan Model -
View -Controller (MVC), dimana desain MVC sudah 
merupakan standar umum dalam m embangun aplikasi 
web dengan menggunakan servlet java dan Java Server 
Pages ( JSP). framework yang dibuat oleh Apache 
Software Foundation.

304 Pemrograman 2  
 
Gambar 152. Struts Framework Bekerja  
 
Pada saat web container mendeploy aplikasi, 
ActionServlet akan membaca file struts -config.xml yang 
berisi semua konfigurasi yang diperlukan untuk 
menjalankan sistem ini. Ketika ada request dari browser, 
langk ah-langkah berikut akan dijalankan:  
a. Request data akan secara otomatis dibungkus ke 
dalam sebuah object ActionForm.  
b. ActionServlet akan mencari controller (Action class) 
yang sesuai dengan path yang direquest oleh 
browser.  
c. Action class memiliki satu method u tama dengan 
nama execute, yang akan dijalankan untuk melayani 
request. Semua processing yang dibutuhkan seperti 
akses database, perhitungan, dan lain lain dijalankan 
 
305 Pemrograman 2  di dalam method ini. Di sini object model dimasukkan 
ke dalam variable HTTP request atau H TTP session, 
yang selanjutnya akan dipanggil dari halaman JSP.  
d. Setelah processing selesai, method execute tersebut 
akan mengembalikan return value yang akan 
menunjukkan status dari processing.  
e. Selanjutnya, status dari Action class tersebut akan 
digunakan u ntuk menentukan halaman JSP mana 
yang akan ditampilkan.  
f. JSP dievaluasi, object model dirender ke dalam 
halaman HTML, dan response dikirimkan ke browser.  
Selanjutnya kita akan membuat contoh aplikasi 
login menggunakan framework Struts.
